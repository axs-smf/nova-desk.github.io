# NOVA DESK — Image Sources

This version replaces the repeated local product photographs with 12 different Unsplash photographs and uses a deterministic product-to-image mapping.

All selected photo pages were identified as free-to-use Unsplash photographs during the build. The storefront references the image CDN directly so GitHub Pages can load the photographs without bundling large binary assets.

## Important
- No product card uses the previous six NOVA DESK local photographs.
- Each catalog product has its own image URL.
- Product image CSS uses `object-fit: contain`, so photographs are not cropped.
- Category cards use a separate deterministic mapping.
