# NOVA DESK — Image Sources

V6 uses local deterministic image assets. Product and category cards do not depend on external image URLs.

All catalog images are stored under `assets/images/products/` and mapped one-to-one in `data/catalog.json`.

## Image policy
- One unique image per catalog product.
- No external image URLs in the storefront.
- No prices, ratings, buttons, hearts, or promotional copy embedded in product photography.
- Product images use a neutral presentation with the complete object visible.
